🚀 3-STEP SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Start Server
  Command: python api.py
  Verify: http://localhost:5000 loads

Step 2: Fetch Jobs
  - Select sources (e.g., Remotive, Himalayas)
  - Click "Fetch Jobs"
  - Wait for jobs to load

Step 3: Try Modal
  - Click any job card
  - Click "View Details" button
  - Read details in popup
  - Click "Apply Now" or "Close"

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Modal not opening?
  → Refresh the page
  → Check browser console for errors
  → Try different browser

Jobs not showing?
  → Click "Fetch Jobs" first
  → Select at least one source
  → Wait for fetch to complete

Apply button not working?
  → Try opening link manually
  → Check if job URL is still valid
  → Try incognito/private mode

Styling looks wrong?
  → Clear browser cache (Ctrl+Shift+Delete)
  → Hard refresh (Ctrl+Shift+R)
  → Try different browser


🎯 TIPS FOR BEST USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Select Specific Sources First
   → Don't fetch all 17 sources at once
   → Choose 2-3 sources per fetch
   → Faster results, easier to manage

2. Use Search/Filter
   → Search for "Python" to find Python jobs
   → Filter by "Remote" for remote jobs
   → Use country filter for location

3. Review Before Applying
   → Read full description in modal
   → Check salary and requirements
   → Verify it matches your skills

4. Keep Portal Open
   → Apply opens in new tab
   → Keep browsing while waiting
   → Come back to find more jobs

5. Organize Your Applications
   → Take notes (outside portal)
   → Track which jobs you applied to
   → Follow up after applying
