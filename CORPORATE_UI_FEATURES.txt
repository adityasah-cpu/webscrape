KEY FEATURES:

✨ DESIGN
  • Modern dark sidebar with professional logo
  • Clean white content area with subtle shadows
  • Gradient colored cards for visual appeal
  • Smooth hover animations and transitions
  • Professional color scheme (blues, grays)

🎯 NAVIGATION
  • Source selection in grouped categories
  • Badge showing job count per source
  • Large prominent "Fetch Jobs" button
  • Loading spinner with status message
  • Last fetch timestamp

📊 DASHBOARD
  • Three gradient stat cards (Remote/Hybrid/Onsite)
  • Real-time updates when jobs are fetched
  • Emoji icons for visual clarity
  • Large, readable numbers

🔍 FILTERING
  • Real-time keyword search (title + company)
  • Work type selector (Remote/Hybrid/Onsite)
  • Country/location filter
  • Instant results update (no page reload)
  • Responsive layout

💼 JOB CARDS
  • Beautiful card layout with hover lift effect
  • Color-coded work type badges
  • Structured metadata (location, country, date)
  • Salary display in success green
  • Direct "Apply Now" button with link

📱 RESPONSIVE
  • Sidebar collapses on mobile
  • Flexible grid layout
  • Touch-friendly buttons
  • Optimized for all screen sizes

📥 EXPORT
  • One-click CSV download
  • All filtered jobs included
  • Opens in Excel/Sheets

📄 PAGINATION
  • 10 jobs per page
  • Numbered pagination buttons
  • Jump to any page

SETUP:

  1. pip install flask flask-cors
  2. python api.py
  3. Open http://localhost:5000
  4. Select sources → Click Fetch → Browse jobs!
