  ─────────────────────────────────────────────────────────────────────────
  Windows: https://www.postgresql.org/download/windows/

  Linux:   sudo apt-get install postgresql

  Step 2: Update PostgreSQL Password
  ─────────────────────────────────────────────────────────────────────────
  File: postgres_db.py
  Find: 'password': 'postgres',
  Change to your PostgreSQL password

  Step 3: Start Flask Server
  ─────────────────────────────────────────────────────────────────────────
  Command: python api.py

  This will:
    • Create job_portal database
    • Create all required tables
    • Start server at http://localhost:5000

  Step 4: Verify Connection
  ─────────────────────────────────────────────────────────────────────────
  Command: curl http://localhost:5000/api/db-info

  Should show: "database": "PostgreSQL"

                        💾 DATABASE SCHEMA

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PostgreSQL automatically creates these tables:

  jobs (Primary table for job listings)
  ├─ id SERIAL PRIMARY KEY
  ├─ url VARCHAR(500) UNIQUE
  ├─ title VARCHAR(255)
  ├─ company VARCHAR(255)
  ├─ work_type VARCHAR(50)
  ├─ country VARCHAR(100)
  ├─ location VARCHAR(255)
  ├─ job_type VARCHAR(50)
  ├─ category VARCHAR(100)
  ├─ salary VARCHAR(100)
  ├─ date VARCHAR(50)
  ├─ source VARCHAR(100)
  └─ added_at TIMESTAMP

  stats (Cache for statistics)
  ├─ id SERIAL PRIMARY KEY
  ├─ stat_key VARCHAR(100)
  ├─ stat_value JSONB
  └─ last_updated TIMESTAMP

  fetch_log (Track fetch operations)
  ├─ id SERIAL PRIMARY KEY
  ├─ sources TEXT
  ├─ jobs_count INTEGER
  ├─ status TEXT
  └─ fetched_at TIMESTAMP
