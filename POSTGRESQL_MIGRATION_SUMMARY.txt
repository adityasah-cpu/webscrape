📊 DATABASE SCHEMA
================================================================================

PostgreSQL creates 3 tables automatically:

1. jobs
   ├─ id (SERIAL, PRIMARY KEY)
   ├─ url (VARCHAR(500), UNIQUE)
   ├─ title, company, work_type, country
   ├─ location, job_type, category, salary
   ├─ date, source
   └─ added_at (TIMESTAMP)

2. stats
   ├─ id (SERIAL, PRIMARY KEY)
   ├─ stat_key (VARCHAR(100))
   ├─ stat_value (JSONB)
   └─ last_updated (TIMESTAMP)

3. fetch_log
   ├─ id (SERIAL, PRIMARY KEY)
   ├─ sources (TEXT)
   ├─ jobs_count (INTEGER)
   ├─ status (TEXT)
   └─ fetched_at (TIMESTAMP)

🔧 COMMON TASKS
================================================================================

Connect to Database:
  psql -U postgres -d job_portal

View Jobs:
  psql -U postgres -d job_portal -c "SELECT COUNT(*) FROM jobs;"

Backup Database:
  pg_dump -U postgres job_portal > backup.sql

Restore Database:
  psql -U postgres job_portal < backup.sql

Clear All Jobs:
  psql -U postgres -d job_portal -c "DELETE FROM jobs;"

View Latest Jobs:
  psql -U postgres -d job_portal -c \
    "SELECT title, company FROM jobs ORDER BY added_at DESC LIMIT 10;"

🚨 TROUBLESHOOTING

Issue: "Connection refused"
Fix:   Start PostgreSQL service

Issue: "FATAL: Ident authentication failed"
Fix:   Check password in postgres_db.py

Issue: "database job_portal does not exist"
Fix:   Run python api.py (creates database)

Issue: "Data not showing"
Fix:   Verify import in api.py says postgres_db not mysql_db

Issue: "psycopg2 not found"
Fix:   pip install psycopg2-binary
